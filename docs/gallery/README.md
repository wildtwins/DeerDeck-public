# Public sample gallery

These are captures of DeerDeck's actual `MainActivity` and Compose UI, rendered
by Robolectric 4.14.1 with Android API 35 native graphics on a development host.
They are **host-rendered app captures, not physical-device or emulator screenshots**.
The production UI source is unchanged from the preview APK's source revision.
No screen was redrawn, generated by AI, or composited from private screenshots.

All sightings, dates, counts, notes, and the labels **Demo Meadow** and
**Sample Grove** are fictional test fixtures. The test uses no coordinates,
photos, recordings, accounts, or Drive folder. Location capture and automatic
backup are disabled inside the isolated test environment. Fixtures exist only
in `src/test`; the downloadable APK starts with an empty dataset.

The 17-second GIF is a timed slideshow of five app captures: Observe, a real
Doe-count action, Stats, History, and Profiles. It is not a screen-recorded video.
The four full-size PNGs are unchanged renderer outputs; the GIF uses palette
encoding. Fonts, emoji, system bars, timing, and hardware behavior may differ
on a device. Some Observe tile text is clipped in the host render; device layout
has not been validated. Test actions invoke the app's accessibility semantics;
they do not verify physical touch input. Review [installation and test limitations](../try-preview.md).

## Reproduce

With the documented JDK/Android SDK available, run from the repository root:

```sh
./gradlew testDebugUnitTest --tests '*PublicGalleryTest' --rerun-tasks
python scripts/package-public-gallery.py
```

Use `gradlew.bat` on Windows. The packaging script requires Python 3 and Pillow.
The test writes only to `app/build/public-gallery`; the script copies the four
approved views to this directory and creates the slideshow and SHA-256 manifest.
Dates are relative to the test run, so regenerated pixels can differ.
Visually inspect every capture for rendering quality and privacy before committing.
